Myelin unified theme and model motion update

Apply to the existing native visual project/runtime 0.2.19, after the earlier native visual updates. No new native dependency or APK is required.

Changes
- Shared warm ivory surfaces, ink text, coral buttons, serif headings and matching navigation throughout the app.
- Today retains its dark object stage. The entire area below it now uses the shared light theme.
- Larger object stage and silhouette-based camera framing for every model.
- Six-second cycle retained. A 560ms fade-through replaces the sideways turn/squeeze.
- Each object returns to its selected angle, with gentle breathing and reduced-motion support.
- Model loading and local assets remain unchanged. No connection or glass feature is included.

Apply
1. Extract this ZIP into the myelin-latest project root, replacing included files.
2. git add --pathspec-from-file=MYELIN-DESIGN-FILES.txt
3. git -c user.name="Myelin" -c user.email="myelin@local" commit -m "Unify Myelin theme and refine object motion"
4. npx eas-cli@latest update --channel preview --environment preview --platform android --message "Unified Myelin design and larger models"

Validation
TypeScript; Today, Focus, Review, Progress and visual structure checks; 37 text/surface contrast pairs; five-model framing at three aspect ratios; uniform scaling, six-second cycling, orientation continuity and reduced motion checks. Android production export checked separately before delivery.

The geometry tests do not validate GPU rendering on a physical Android device. Check the final appearance, text wrapping and native graphics on your phone. This package has not been published.
