## Full description

MYELIN is a focused study companion built around active recall and realistic planning.

Create the topics you actually need to study, add recall questions, and attempt answers before revealing the reference. MYELIN helps organize due reviews, nearby exams and available study time into a clear next action instead of an impossible task list.

Focus mode supports timed study blocks, breaks, a five-minute launch for getting started, and a distraction parking lot. The mistake notebook turns errors into corrections and retests. Progress views focus on evidence such as review results, confidence calibration and planned-versus-actual study time.

Core study data works offline. Account and cloud-sync features are optional, and reminder controls include quiet hours and non-manipulative notification styles.
